# How to change the look of your website

Change the words after the colons in the lines above, then commit.
Your website will update in a minute or two. Leave the words before
the colons exactly as they are.

If you type something the website builder doesn't understand, it uses
the theme's normal setting instead, and your website's Build report
tells you which line it skipped. You can't break your site from this file.

## Theme

Start here. A theme sets all the colors and fonts at once. Choose one:

- aurora: indigo and magenta glows with crisp modern fonts
- sunset: warm orange and rose with friendly modern fonts
- ocean: cool teal and blue with clean modern fonts
- forest: sage greens and amber with a soft modern serif font
- parchment: warm paper tones and old-book fonts, good for fantasy and history games
- arcade: neon colors on a dark screen with a retro computer font
- midnight: light text on deep navy with a soft violet glow
- minimal: black and white with simple, plain fonts

## Style

The style changes the effects, and works with any theme:

- glass: soft color glows behind frosted, see-through panels
- soft: the same glows, with solid panels instead of see-through ones
- flat: no glows, see-through panels, or shadows, for a plain, classic look

## Colors

To keep the theme's color, write "default". Otherwise you can write:

- a color name, like: crimson, navy, goldenrod, teal, darkslategray
- a hex code from a color picker, like: #7b2d26

Search for "HTML color names" or "color picker" to find more.

- Main color: headings, the glow in the top corner, and the start of each gradient
- Accent color: links, topic labels, and the end of each gradient
- Background color: the page behind everything
- Text color: your writing

If your text and background colors are too close for people to read
easily, the Build report will warn you.

## Fonts

To keep the theme's font, write "default". Otherwise, write the name of
any font from fonts.google.com exactly as it appears there. Some ideas:
Inter, Sora, Outfit, Fraunces, Space Grotesk, Playfair Display, Lora,
Cinzel, Bangers, Press Start 2P, Comic Neue, Nunito.

## Other settings

- Text size: small, medium, or large
- Corners: rounded or square
- Topic labels: show or hide (the small "Concept", "Task", and
  "Reference" labels above each page title)
- Logo: none, or the file name of a picture you uploaded to the images
  folder, like: logo.png
- Tagline: a short sentence shown under the title on your home page,
  or none
- Footer text: any short sentence shown at the bottom of every page,
  or none

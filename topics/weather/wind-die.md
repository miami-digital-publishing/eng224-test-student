# Wind Die Results {.reference}

The wind die has six faces.

| Face | Result |
|---|---|
| North arrow | Wind blows north |
| East arrow | Wind blows east |
| South arrow | Wind blows south |
| West arrow | Wind blows west |
| Double arrow | Wind keeps its current direction, and every captain gains +1 speed this round |
| Storm cloud | The wind doesn't change. Move the storm marker one region in the wind's direction |

If the storm would move off the edge of the map, it moves to region 7 instead.

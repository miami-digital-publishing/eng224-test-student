# Set Up a Solo Game {.task}

1. Set up the sky map using the [two-player setup](/topics/setup/two-player-setup.md).
2. Set up your player area as normal, but take 12 coins.
3. Choose a color for the rival and place its airship on Windhollow.
4. Place the rival's dock marker on space 0 of the renown track.
5. Shuffle the rival captain deck and place it face down.
6. Choose a difficulty.
    - **Easy:** remove the two cards marked with a crown.
    - **Normal:** use all twelve cards.
    - **Hard:** the rival starts with 5 renown.

You always take the first turn of each round.

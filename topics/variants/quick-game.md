# Quick Game {.concept}

The quick game lasts six rounds instead of eight, and takes about 45 minutes. It's a good way to teach new players.

## Changes to setup

- Start the round tracker on space 3.
- Give each captain 3 extra starting coins.
- Deal each captain one contract instead of letting them choose.

## Changes to play

- Skip the dusk wage payment in the first round.
- Upgrades cost 1 coin less.

Everything else, including scoring, stays the same.

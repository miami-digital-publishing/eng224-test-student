# Dawn Phase {.task}

The first captain runs the dawn phase. It takes less than a minute.

1. Reveal the top card of the event deck and read it aloud.
2. Follow the card's instructions.
    - If the card says **Later**, leave it face up beside the board until its effect happens.
3. Roll the wind die.
4. Turn the wind compass on the board to match the arrow on the die.
    - If the die shows the storm face, leave the compass as it is and move the storm. See [Storms](/topics/weather/storms.md).
5. Check whether any airship is now in a storm region.
    - Those captains must [ride out the storm](/topics/weather/ride-out-storm.md) before the action phase begins.

The action phase begins with the first captain.

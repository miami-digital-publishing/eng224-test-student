# End of a Round {.task}

1. Move the round tracker forward one space.
2. Discard any event cards whose effect has ended.
3. Check whether the game is over.
    - If the round tracker moved past space 8, go to [End of the game](/topics/scoring/end-of-game.md).
4. If the game isn't over, start the next round with the [dawn phase](/topics/turns/dawn-phase.md).

> **Tip:** Before starting the next round, take a moment to check the renown track. Captains often forget to move their markers when they build docks or upgrades.

# Scoring Table {.reference}

|---|---|---|
| Fulfilled contract | 2 to 7, as printed | During the game |
| Contract at Brightspire | +1 | During the game |
| Dock | 2 each | During the game |
| Upgrade | 1 each | During the game |
| All three docks built | 3 | End of the game |
| Full crew (one of each type) | 4 | End of the game |
| Coins | 1 per 10 coins | End of the game |
| Cargo in your hold | 0 | |
| Unfulfilled contracts | 0 | |

A typical winning score in a four-player game is between 35 and 45 renown.

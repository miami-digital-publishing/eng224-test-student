# How to win {.concept}

The first player to get three marks in a row wins. A row can go in three directions:

- **Horizontal:** across any of the three rows
- **Vertical:** down any of the three columns
- **Diagonal:** from one corner, through the center, to the opposite corner

## When nobody wins

If all nine squares are filled and neither player has three in a row, the game is a tie. Experienced players tie often, because each can block the other's lines.

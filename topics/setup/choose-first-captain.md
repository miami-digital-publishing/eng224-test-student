# Choose the First Captain {.task}

The first captain takes the first turn of each round. The role moves to the left at the end of every round.

1. Each player rolls the wind die.
2. The player whose arrow points closest to the top of the board becomes the first captain.
    - If two or more players tie, those players roll again.
3. Give the first captain the gold compass token.
4. Starting with the player to the **right** of the first captain and going counterclockwise, each player places their airship figure on any island.
    - Two airships can't start on the same island.

The last player to place an airship has the best choice of contracts, which balances the advantage of going first.

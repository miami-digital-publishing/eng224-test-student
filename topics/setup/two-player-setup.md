# Setup for Two Players {.task}

A two-player game uses a smaller sky. Follow the normal setup, with these changes.

1. Fold the sky map so that only regions 1 through 5 are visible.
2. Use only eight island tiles.
    - Remove Hollowrock, Cloudmarket, Emberlight, and Stillwater.
3. Fill each island's market with two cargo tokens of each good, instead of three.
4. Give each captain 10 starting coins.
5. Deal only three cards to the crew market.
6. Place a neutral dock marker (any unused color) on Windhollow.
    - When a captain lands at the neutral dock, they pay 1 coin to the bank.

The rest of the game plays normally.
